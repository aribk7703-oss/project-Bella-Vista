Bella Vista Restaurant – Project Documentation

Executive Summary: Bella Vista is a modern static website template for an Italian restaurant. It’s built with plain HTML5, CSS3 organized as a single-page design with sections for Home (hero banner), Menu, About, Contact (reservation form), and Footer.

Responsive Design: Mobile-friendly layout with CSS media queries for various screen sizes.
Sections: Home (hero banner with call-to-action), Menu (appetizers, main courses, desserts), About, and Contact (reservation form).
Interactivity: Form validation and smooth hover effects using CSS.
Styling: Modern look with CSS grid/flexbox and hover transitions.


Technology	Purpose
HTML5	Markup structure of the website
CSS3 (Flexbox, Grid)	Layout and styling
